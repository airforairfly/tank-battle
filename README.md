# 坦克大战 Tank Battle

一个用原生 HTML5 Canvas + JavaScript 实现的单文件经典坦克大战（Battle City）小游戏，双击 `index.html` 即可在浏览器中游玩，无需任何依赖或构建工具。

## 玩法

- 操作己方坦克，守住地图下方的基地 🏠，消灭所有敌军坦克即可过关。
- 基地被摧毁，或生命耗尽，则游戏结束。

## 操作

| 功能 | 按键 |
|------|------|
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 射击 | `空格` 或 `J` |
| 暂停 / 继续 | `P` |
| 重新开始 | `R` |
| 开始游戏 | `空格` / `回车` / 点击画面 |

## 元素说明

- 🧱 砖墙：可被子弹摧毁。
- 🛡 钢墙：普通子弹无法摧毁，升到 3 星后可击穿。
- 🌊 水：坦克不能通过，子弹可以飞过。
- 🌿 草丛：会遮挡坦克（敌我子弹都能穿过）。
- 🏠 基地：被打中即游戏结束，注意保护！

## 道具

- `S` 升星：提升火力，最高 3 星（3 星可击穿钢墙）。
- 🛡 护盾：短时间无敌。
- 💣 清屏：消灭场上所有敌人。
- ❤ 加命：生命 +1。

## 敌人

| 类型 | 颜色 | 特点 |
|------|------|------|
| 普通坦克 | 红 | 基础敌人 |
| 快速坦克 | 青 | 移动快 |
| 强力坦克 | 紫 | 需要 2 发子弹 |
| 装甲坦克 | 绿 | 需要 3 发子弹 |

共 3 个关卡，敌人数量和强度逐关递增。

## 本地运行

直接双击 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```
